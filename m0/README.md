# M0 · 사진 50장으로 인식·중복 판별 검증

목표: 갤러리 사진만으로 옷장을 만들 때 사용자가 **옷 10벌당 몇 번 고쳐야 하는가**를 잰다. 합격 기준은 결과를 보기 전에 정했다(사전 등록).

| 지표 | 기준 |
| --- | --- |
| 검출 재현율 (상의·하의·아우터·원피스·신발) | ≥ 85% |
| 대분류 정확도 | ≥ 90% |
| 색 정확도 (기본 색명) | ≥ 80% |
| 같은 옷 판별 B-cubed F1 | ≥ 0.80 |
| 과병합률 (다른 옷을 한 벌로) | ≤ 5% |
| 수정 부담 (옷 10벌당) | ≤ 3 |

## 1. 사진 고르기 (약 15분)

`m0/photos/`에 50장을 넣는다. 이 폴더는 git에 올라가지 않는다.

- 거울 셀카 20, 전신 OOTD 20, 상반신 셀카 10 (옷장 한 컷·플랫레이는 스캐너의 다른 경로라 이번에는 넣지 않는다)
- **같은 옷이 여러 사진에 반복해서 나오게** 고른다. 반복이 없으면 중복 판별을 잴 수 없다.
- 비슷한 다른 옷(예: 검정 상의 두 벌)을 일부러 넣는다.
- iPhone HEIC 그대로 괜찮다.

## 2. 정답 라벨 (약 45분, 스캐너 결과를 보기 전에)

`m0/label.html`을 브라우저로 연다(HEIC는 Safari에서 보인다). 사진 폴더를 열고, 사진마다 보이는 옷을 모두 등록한다. 같은 옷은 처음 만든 번호를 골라 붙인다. 끝나면 `labels.csv`를 내려받아 `m0/labels.csv`로 저장한다.

모델 결과를 먼저 보면 그 답에 끌려 정답이 오염된다(기준점 효과). 라벨을 먼저 한다.

## 3. 스캔과 평가

```
cd scanner
uv sync
uv run closet-scan scan ../m0/photos --out ../out
uv run closet-scan eval ../out ../m0/labels.csv --sweep --md ../out/m0-result.md
```

Claude 태깅과 쌍 검증까지 비교하려면 결과 폴더를 따로 둔다.

```
uv sync --extra claude
export ANTHROPIC_API_KEY=...
uv run closet-scan scan ../m0/photos --out ../out-claude --tagger claude --verify
uv run closet-scan eval ../out-claude ../m0/labels.csv --md ../out-claude/m0-result.md
```

## 4. 결과 읽기

- 표의 괄호는 95% Wilson 신뢰구간이다. 50장은 작아서 구간이 넓다. M0은 모델 확정이 아니라 **파이프라인 간 순위와 치명적 실패 유형**을 찾는 단계다.
- "질문에 답하면" 표는 보고서의 "같은 옷인가요?"에 정답대로 답했을 때의 변화다. 질문 설계가 수정 부담을 실제로 줄이는지 본다.
- `--sweep` 표는 같은 데이터로 기준값을 고른 것이라 낙관적이다. 베타 전에 다른 사람 3~5명의 사진으로 다시 확인한다.
- 결과와 결정은 `docs/DECISIONS.md`에 한 줄씩 적는다.
